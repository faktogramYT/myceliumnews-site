Privacy Policy

Last updated: 6 November 2026

This Privacy Policy explains how personal data is handled by the MyceliumNEWS website and by the MyceliumNEWS Desktop application (together, the “Services”). The Services are operated by MyceliumNEWS (“MyceliumNEWS”, “we”). Contact: mycelium6666@gmail.com.

1. Summary

  • The website sets no cookies, has no forms, and uses no analytics, advertising or third-party scripts or fonts.
  • The Desktop application runs only on the user's own computer. We run no server for it, so we receive none of the data it reads.
  • It reads statistics from a TikTok account only after the holder of that account approves access on TikTok's own login page.
  • The data stays on that computer, is not sold, shared or used for advertising, and can be deleted at any time.

2. The website

The website is a static site hosted on GitHub Pages. We do not collect personal data through it and we do not set cookies. As with any web hosting, the hosting provider, GitHub, may process technical information such as your IP address and browser details in server logs when you visit; see GitHub's privacy statement. We do not have access to those logs. If you write to us by email (see Contact), we process your email address and message only to answer you.

3. The MyceliumNEWS Desktop application

3.1 What the application reads from TikTok

When you connect an account with TikTok Login Kit and approve the permissions, the application requests the following read-only data through the TikTok Display API:

ScopeDataStored locally?
user.info.basicOpen ID, display name, profile picture URLOpen ID is stored with the access token; display name is stored in snapshots; the profile picture URL is received but not stored.
user.info.statsFollower count, following count, like count, video countYes, in dated snapshots.
video.listFor each public video: ID, title or description, creation time, duration, cover image URL, share URL, view count, like count, comment count, share countYes, in dated snapshots.

The application does not read direct messages, the text of comments, lists of followers or advertising data, and it does not request any permission to post, upload, edit or delete content.

3.2 What is stored, and where

  • Authorization tokens (an access token, a refresh token, the Open ID, the granted scopes and expiry times) are stored in a local file on the user's computer so that the application can refresh access without asking the user to log in again. They are never displayed, logged or transmitted anywhere except to TikTok's own API.
  • Statistics snapshots are stored as files in a folder on the user's computer, one per day on which the user refreshes the data.
  • The application's configuration contains the application's TikTok client key and client secret. These identify the application, not the user.

We do not receive, copy or back up this data on any server we control. If the user backs up their computer, the files are subject to that backup.

3.3 Purpose and legal basis

The data is used only to display the account's statistics to the person who authorized access and to let them compare the numbers over time. Where data protection law such as the GDPR applies, the basis is the consent given by the account holder when they approve access on TikTok, which they can withdraw at any time as described below.

3.4 Sharing

We do not sell, rent or share this data, and we do not use it for advertising, profiling, or training machine-learning models. The application communicates only with TikTok's servers (tiktok.com and open.tiktokapis.com) and with the browser on the same computer.

3.5 Retention and deletion

  • Tokens are kept until the user disconnects or until they expire. TikTok decides the lifetime of tokens.
  • Snapshots are kept until the user deletes the files.
  • Disconnect: the Disconnect button in the application deletes the stored tokens and asks TikTok to revoke the access token.
  • Revoke on TikTok: the account holder can also remove the application's access from the app permission settings of their TikTok account.
  • Delete snapshots: delete the snapshot files from the application's statistics folder.

Because we hold no copy of the data, we cannot retrieve or delete it for you remotely; the steps above remove all of it.

4. Children

The Services are not directed to children, and we do not knowingly collect personal data from children.

5. Your rights

Depending on where you live, you may have the right to access, correct or delete your personal data, to restrict or object to processing, and to complain to a data protection authority. For the website and for any email you send us, contact us at mycelium6666@gmail.com. For data inside the Desktop application, you can exercise these rights yourself using the steps in section 3.5.

6. Security

Sign-in uses TikTok's authorization flow for desktop applications with PKCE and a one-time state value, and a loopback redirect to the user's own computer. Tokens are stored only in the application's local configuration folder. No method of storage is perfectly secure, and we recommend keeping your computer's user account protected.

7. TikTok

When you log in with TikTok, TikTok's own terms and privacy policy apply to that login and to your TikTok account. MyceliumNEWS is not affiliated with TikTok.

8. Changes

We may update this policy. The date at the top shows the latest version, and significant changes will be described on this page.
